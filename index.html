Panduan Hosting & Deployment MPI Online (Gratis)

Langkah mudah mempublikasikan aplikasi MPI ini agar dapat diakses seluruh siswa melalui HP / Laptop.

1. Netlify Drop Paling Mudah

1. Unduh paket ZIP dengan tombol di atas.
2. Buka app.netlify.com/drop.
3. Drag & drop file index.html.
4. Link web MPI langsung aktif dalam 5 detik!

2. Vercel / GitHub Pages

1. Upload file ini ke repository GitHub.
2. Aktifkan **GitHub Pages** di menu Settings -> Pages.
3. Atau hubungkan repository ke **Vercel.com** untuk deployment otomatis dengan custom domain gratis.

3. Penggunaan Offline

File index.html ini **100% Standalone**. Anda cukup menyimpan file ini di HP / Flashdisk dan membukanya langsung via browser (Chrome/Edge) tanpa perlu koneksi internet server!
